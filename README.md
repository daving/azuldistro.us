# Azul Distro Global LLC Website

This repository contains a modernized, responsive single-page site for Azul Distro Global LLC, built with Bootstrap 5 and custom styling. The site is optimized for deployment on GitHub Pages.

## Local development

Open `index.html` in your browser or use a lightweight HTTP server for local preview:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Structure

- `index.html` – Landing page layout with sections for hero, about, services, industries, testimonials, and contact.
- `assets/css/styles.css` – Custom theme and component styling.
- `assets/js/main.js` – Progressive enhancements (dynamic year and navbar scroll effect).

## Deployment

Push the contents of the `main` branch to GitHub and enable GitHub Pages with the root directory selected.
